# profile/

Put your resume here: `.pdf`, `.txt` or `.md`, under any file name. The newest file is used.

Everything in this folder except this README is git-ignored. Your resume is read on every run, and the AI only
ever gets a copy with your name, contact details, links, address and other personal details removed. Run
`uv run jobradar resume` to see that copy.

If a PDF comes out garbled (two-column or Canva layouts often do), save a plain `resume.txt` here instead.
